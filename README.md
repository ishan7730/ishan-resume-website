# Ishan Aadi — Personal Resume Website

A responsive personal portfolio built with HTML5 and CSS3.

## Files
- `index.html` — website content and structure
- `style.css` — layout, typography, colours, cards, responsive styling

## Run locally
Open `index.html` in a web browser. An internet connection is required for the Google Fonts used in the design; the site will fall back to system sans-serif fonts if unavailable.

## Publish with GitHub Pages
1. Create a new public repository named `ishan-resume-website` in the GitHub account `ishan7730`.
2. Upload `index.html`, `style.css`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. After GitHub Pages publishes the site, verify:
   https://ishan7730.github.io/ishan-resume-website/

## Before submission
- Confirm the live website opens publicly.
- Confirm the GitHub repository is public.
- Check your personal details and role descriptions for accuracy.
- Update the submission PDF with the verified live URL if the repository name or Pages URL differs.

## CSS concepts demonstrated
Element, class and ID selectors; CSS custom properties; Flexbox; CSS Grid; sticky navigation; positioning; hover transitions; typography; spacing; colour palette; responsive media queries.
